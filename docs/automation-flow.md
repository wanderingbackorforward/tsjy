# V2 自动化数据接入流程

## 目标

把现场给来的 Excel / CSV / docx 表格，尽量自动完成：

1. 文件进入 incoming 目录；
2. 自动判断资料类型；
3. 上传到后端 import API；
4. 自动识别表头；
5. 用字段别名表推荐映射；
6. 低置信度字段进入人工确认；
7. 自动校验必填字段、单位、日期、环号；
8. 校验通过后入库；
9. 移动到 processed；
10. 失败文件移动到 rejected，并保留错误日志。

## 资料类型识别规则

| 文件名关键词 | data_category |
|---|---|
| 环号 / 里程 / 进度 | ring_mileage |
| 掘进 / 盾构 / PLC / 参数 | shield_operation |
| 监测 / 沉降 / 测点 | monitoring_reading |
| 风险源 / 穿越 / 建构筑物 | risk_source |
| 注浆 | grouting |
| 泥水 / 泥浆 | slurry |
| 事件 / 报警 / 异常 | event |

## 自动化边界

系统可以自动做：
- 文件识别；
- 表头读取；
- 字段推荐；
- 基础校验；
- 低风险入库。

系统不应该自动做：
- 把不确定字段强行映射；
- 把缺少环号/日期的表强行入库；
- 把真实报警改成正常；
- 把方案数据当成实测数据。

## 推荐流程

第一版先做半自动：

文件上传 → 自动预览 → 自动推荐映射 → 人确认 → 校验 → 入库

第二版再做 watch 目录自动导入：

incoming 目录 → 自动上传 → 自动校验 → 自动入库或进入 rejected

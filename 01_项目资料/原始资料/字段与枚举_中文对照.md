# 通苏嘉甬 字段与枚举 中文对照

> 更新时间：2026-11-22　｜　状态：生效中　｜　当前版本：—

导入包里的列名和枚举值是英文，数据库里保持英文不改（改了会破坏 SQL）。这份表用于看懂数据、在 Excel 里查数、写查询。

## 1. 七张表用途

| 表 | 中文名 | 用途 |
|---|---|---|
| `stg_file_source_document` | 源文件登记 | 111 个原始文件的路径、类型、日期 |
| `stg_file_daily_report_meta` | 日报元数据 | 每份日报的施工单位、监理、监测单位、天气、环号、里程 |
| `stg_file_monitoring_point` | 监测点 | 1,339 个测点的编号、对象、项目、阈值、位置 |
| `stg_file_monitoring_reading` | 监测读数 | 19,000 条读数：本次值、累计变化、日变化、变化速率、告警等级 |
| `stg_file_extraction_evidence` | 解析证据 | 每条数据来自哪一页、哪张表、哪一行、原文是什么 |
| `stg_file_extracted_page` | 逐页解析 | 2,296 页的文本/表格提取结果，含待 OCR 的页 |
| `stg_file_data_quality_issue` | 数据质量问题 | 24,628 条待修数据问题清单 |

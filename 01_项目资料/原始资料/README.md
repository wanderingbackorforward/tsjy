## 四、规则

| 规则 | 内容 |
|---|---|
| 只读 | 程序只读打开；不写回、不原地改名、不就地清洗 |
| 原样保留 | 保留甲方原文件名、原格式、原单位；换算只在处理后数据侧产生 |
| 批次隔离 | 找回或新交付的文件放 `批次YYYYMMDD/`，不覆盖旧批次 |
| 每批三件套 | `交付说明.md` + `文件清单.csv` + `文件哈希.md5`，缺一不算登记完成 |
| 缺失表示 | 未交付就留空，不放 0 / -1 / 空串占位 |
| 登记 | 新批次完成后，同步更新本 README 的规模与清单表 |

# 通苏嘉甬 导入包 使用说明（中文）

> 更新时间：2026-11-22　｜　状态：可执行　｜　当前版本：—

原包里的 `file_sql_package_readme.md` 和 `server_import_commands.sh` 是英文，而且脚本里的 psql 参数被生成器清空过，直接跑会失败。这份中文说明按本机与服务器的实际路径重写，照下面做即可。

## 1. 包里有什么

| 文件 | 作用 |
|---|---|
| `00_schema.sql` | 建通苏业务表（`source_document`、`monitoring_point`、`monitoring_reading`、`extraction_evidence` 等 19 张） |
| `01_create_file_staging_tables.sql` | 建 7 张 `stg_file_*` 中间表 |
| `02_copy_file_staging_data.sql` | 用 `COPY` 把 CSV 灌进中间表（快，推荐） |
| `03_insert_file_staging_data.sql` | 用 `INSERT` 灌数据（备选，比 02 慢） |
| `04_upsert_file_to_current_tables.sql` | 中间表写入业务表，`ON CONFLICT` 更新，可重复执行 |
| `postgres_ready/*.csv` | 7 个数据文件，共 64.9 MB |
| `server_import_commands.sh` | 一键脚本（已修好，中文提示） |

## 3. 前置条件

- PostgreSQL 12+，库 `shield_monitor`，账号 `shield_user`
- 密码从服务器 `/opt/nycj/1gongqu-backend/.env` 取，**不要写进脚本或文档**
- 当前库只有宁扬的 20 张 `gn_*` 表，通苏业务表还没建，所以要跑 `00_schema.sql`

## 4. 一键导入（服务器）

```bash
cd /opt/tsjy-file-import
export PGPASSWORD='数据库密码'
./server_import_commands.sh
```

业务表已经存在时跳过建表：

```bash
SKIP_SCHEMA=1 ./server_import_commands.sh
```

## 5. 手工导入（等价步骤）

```bash
cd /opt/tsjy-file-import
export PGPASSWORD='数据库密码'
P="psql -h 127.0.0.1 -p 5432 -U shield_user -d shield_monitor -v ON_ERROR_STOP=1"

$P -f 00_schema.sql                       # 1. 建业务表（已有表就跳过）
$P -f 01_create_file_staging_tables.sql   # 2. 建中间表
$P -f 02_copy_file_staging_data.sql       # 3. COPY 灌数据
$P -c "SELECT COUNT(*) FROM stg_file_monitoring_reading"   # 4. 应为 19000
$P -f 04_upsert_file_to_current_tables.sql                 # 5. 写业务表
$P -c "SELECT COUNT(*) FROM monitoring_reading"            # 6. 应为 19000
```

本机导入把路径换成 `D:/mine/myprojects/通苏嘉甬/01_项目资料/原始资料/导入包`，`02` 里的路径已经改好。

## 7. 回滚

只删中间表，不动业务表：

```sql
DROP TABLE IF EXISTS stg_file_data_quality_issue;
DROP TABLE IF EXISTS stg_file_extracted_page;
DROP TABLE IF EXISTS stg_file_extraction_evidence;
DROP TABLE IF EXISTS stg_file_monitoring_reading;
DROP TABLE IF EXISTS stg_file_monitoring_point;
DROP TABLE IF EXISTS stg_file_daily_report_meta;
DROP TABLE IF EXISTS stg_file_source_document;
```

业务表要退回导入前状态，用当天备份恢复（宁扬 `pg_dump` 已包含整个 `shield_monitor`）。
